# Retail Sales Analytics

## Project Overview
This project analyzes retail sales data using Excel, SQL, Python, and Power BI. The objective is to clean, process, analyze, and visualize retail sales data to generate meaningful business insights.

## Tools & Technologies
- Microsoft Excel
- SQL
- Python (Pandas, Matplotlib)
- Power BI

## Project Workflow
1. Data Collection
2. Data Cleaning using Excel & Python
3. Data Analysis using SQL
4. Customer Segmentation
5. Interactive Dashboard Creation using Power BI
